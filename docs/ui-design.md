# IntraFlow UI 디자인 기준

IntraFlow는 표 중심의 컴팩트 업무 도구다. 한 화면에 필요한 정보를 충분히 표시하되, 즉시 실행할 동작과 읽기 전용 정보를 명확히 분리한다.

## 화면 구조

- 상단 명령 바: 제품명, 사용자, 자동 Pull, Outbox, 동기화 상태, Pull·Push·전체 동기화
- 주 탭: 내 업무, 팀 업무, 관리, 개인 설정, 동기화
- 페이지 헤더: 화면명과 현재 표시 건수
- 콘텐츠: 필터→목록/캘린더/현황→읽기 전용 상세
- 1250px 이상은 목록·상세 분할, 미만은 목록과 상세를 전환하고 `목록으로`를 제공한다.

## 시각 원칙

- IGLOO Green은 주요 버튼, 선택, 진행률에만 사용한다.
- Amber는 마감 임박·일정 경고, Red는 지연·실패·삭제, Gray는 완료·비활성에 사용한다.
- 상태는 색만으로 구분하지 않고 텍스트를 함께 표시한다.
- 기본 간격은 4·8·12·16·24px, 입력은 30px, 버튼은 32px, 아이콘 버튼은 28px다.
- 본문 카드는 그림자 대신 1px 경계선과 8px 모서리를 사용한다.

## 업무 상세 우선순위

1. 전체 경로와 활성·경고 상태
2. 완료량/목표량과 진행률
3. 증감량·누적 완료량·현재 메모 입력
4. 설명·단위·계획 기간·갱신 시각
5. 진행·메모 이력

개인 일정은 제공하지 않는다. 팀 캘린더는 업무 계획 기간을 단일 일정 원본으로 사용한다.

## 검증 크기

- 1100×720: 목록/상세 전환, 필터 줄바꿈, 세로 스크롤 확인
- 1600×950: 목록/상세 동시 표시와 표 열 가독성 확인
- Windows 라이트·다크 및 100%·125%·150% 배율에서 대비와 잘림을 확인한다.
